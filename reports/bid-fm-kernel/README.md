# Scalable FM, FFM and RFF alternatives for historical wholesale auction prices

Original VIN-disjoint chronological validation selects among 10 independently trained FM (rank16/32), exact field-aware FM (rank8) and RFF approximate epsilon-insensitive SVR / Huber regressor variants on full and Lemon training. Original untrimmed 82,380 validation and 83,603 test auctions are unchanged. All trial artifacts contain only validation predictions; independent report evaluates test for exactly ONE validation-selected winner. Separate validation-selected XGBoost/FМ blend tests possible complementary errors without falsely claiming fit-on-honest-OOF residual correction. Full XGBoost is an aggregate unpaired comparator, Lemon XGBoost is paired on identical original auction IDs. No production promotion.
